Hexo + Fluid 搭建个人博客教程

前言

一直想拥有一个自己的博客，用来记录学习、生活和项目经验。经过一段时间的摸索以及ai的帮助，我用 Hexo、Fluid 和 GitHub Pages 搭建并发布了自己的博客。

本文记录 Windows 环境下从准备工具、创建 GitHub 仓库，到安装 Hexo、配置 Fluid、绑定域名和发布文章的过程。命令在 CMD 或 PowerShell 中运行；修改配置文件时使用记事本或 VS Code。

我的博客： https://shawnpeng.top

二、创建 GitHub Pages 仓库

  1. 浏览器登录 GitHub，点击右上角 +，选择 New repository。
  2. 仓库名称填写 你的GitHub用户名.github.io。例如：Shawn-Peng1018.github.io。
  3. 设为 Public，然后点击 Create repository。
  4. 打开仓库的 Settings → Pages，在 Build and deployment 中设置 Source: Deploy from a branch、Branch: master、目录 /(root)，点击 Save。若仓库实际分支叫 main，请选择 main。

在腾讯云 DNSPod 中打开 shawnpeng.top 的 记录管理，添加以下记录。GitHub 官方建议根域名配置四条 A 记录；如果 DNS 服务商套餐限制记录数量，按控制台允许的数量设置，并检查 GitHub Pages 的 DNS 状态。

主机记录 类型 记录值

2. GitHub 账号验证域名

在 GitHub 个人账号 Settings → Pages → Add a domain 添加 shawnpeng.top。GitHub 会提供 TXT 主机记录和值；在 DNSPod 添加相应 TXT 记录，等待解析生效后回到 GitHub 点击 Verify。看到 Verified 表示账号层面的验证完成。

3. 在仓库 Pages 绑定域名

打开博客仓库 Settings → Pages → Custom domain，输入 shawnpeng.top 并保存。

八、常见问题

1. hexo d 提示找不到 Git

安装 Git 后重新打开终端，运行 git --version 检查。如果仍提示找不到，确认 Git 安装程序已将 Git 加入系统 PATH。

2. 提示 Author identity unknown

在终端设置 Git 提交署名：

3. 修改后网站没有变化

确认修改的是博客根目录中的配置文件；在终端重新运行 hexo clean、hexo g，本地预览确认后再运行 hexo d。浏览器可以按 Ctrl+F5 强制刷新。

4. YAML 缩进报错

只用空格，不用 Tab；子项比父项多缩进两个空格；同一配置项不要重复定义。报错行号通常能帮助定位出错位置。

结语

从安装环境、初始化 Hexo，到配置 Fluid、绑定域名和发布文章，过程里有不少细节，但逐项完成后，就能拥有一个可以持续更新的个人博客。之后我会继续用博客记录学习和生活中的收获。
